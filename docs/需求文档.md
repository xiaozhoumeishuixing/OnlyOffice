# Office Online 文档处理系统 - 需求文档

## 目标

开发基于 Java 的 Web 应用，实现在线查看、在线编辑 Word 文档，并支持将 Word 文档转换为 PDF。系统部署于 Linux 服务器，底层依赖 OnlyOffice Document Server，提供 REST API 和简单前端页面。

## 功能范围

- 文档上传：`POST /api/documents/upload`
- 在线预览：`GET /api/documents/{id}/preview`（只读）
- 在线编辑：`GET /api/documents/{id}/edit`，含 `callbackUrl`
- 编辑回调保存：`POST /api/onlyoffice/callback`
- Word 转 PDF：`POST /api/documents/{id}/convert/pdf`
- PDF 下载：`GET /api/documents/{id}/pdf/download`
- 文档列表：`GET /api/documents`

## 非功能要求

- Java 17、Spring Boot 3.x、Maven
- 原生 HTML + JS 前端，使用 OnlyOffice Docs API
- Docker Compose 编排 OnlyOffice Document Server 与 App
- 本地文件系统存储，默认 `/data/files`
- 环境变量支持 `ONLYOFFICE_URL`、`OFFICECLI_URL`、`STORAGE_ROOT`、`CALLBACK_URL`
- 单元测试 + MockWebServer 集成测试
- 中文字体（`fonts-noto-cjk`）保证 PDF 不乱码
