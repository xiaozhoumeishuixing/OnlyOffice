# 项目复盘

## 做得好的

- 需求未明确时先阅读 OfficeCLI 官方 README 再定方案，避免错误集成。
- 文件存储与元数据分离，`DocumentMetadataStore` 预留数据库扩展。
- 文档 URL 统一通过 `/content` 接口暴露，不泄露物理路径。
- 文档 key 绑定 `updatedAt`，保存回调后自动失效缓存。
- MockWebServer 覆盖转换与回调保存两条关键链路。

## 可改进

- 元数据目前为内存实现，重启即失；生产环境建议接入 PostgreSQL/MySQL。
- 转换接口目前同步等待，文件较大时可增加异步任务与状态查询。
- JWT 回调验签、用户身份注入可进一步细化。
- 文档服务器健康检查与 App 启动依赖可增加 compose healthcheck。
