# 技术栈说明

| 层 | 技术 |
|----|------|
| 后端 | Java 17，Spring Boot 3.3.5，Maven |
| HTTP | JDK `java.net.http.HttpClient`，Jackson |
| 前端 | 原生 HTML/CSS/JavaScript，OnlyOffice `DocsAPI.DocEditor` |
| 文档服务 | OnlyOffice Document Server（Docker） |
| 转换 | Document Server `ConvertService.ashx` |
| 可选工具 | OfficeCLI（本地 CLI，仅辅助容器） |
| 存储 | 本地文件系统 `STORAGE_ROOT`，默认 `/data/files` |
| 元数据 | 内存 `ConcurrentHashMap`，通过接口预留数据库扩展 |
| 测试 | JUnit 5，AssertJ，Mockito，OkHttp MockWebServer |
